# Changelog

## [2.0.2] – 2026-08-26

### Обновления зависимостей
- **jQuery** обновлён до версии **3.7.1** (вместо 3.5.1) – повышение безопасности и производительности.
- **Bootstrap** обновлён до версии **4.6.2** (вместо 4.5.2) – исправлены уязвимости и улучшена совместимость.

### Изменения в настройках (setPeople.tpl, setChasy.tpl, setKTU.tpl)
- Добавлен атрибут `step="0.1"` во все поля ввода числовых значений – теперь можно вводить дробные числа (например, 0.5, 1.25) для ставок, КТУ и других параметров.
- В `setKTU.tpl` изменён тип скрытого поля `name="type"` с `ktu` на `setktu` – теперь обработчик `handler.php` корректно распознаёт этот тип.
- В `setPeople.tpl` полностью переработан порядок полей: **Оклад**, **Ставка час**, **Ставка**, **Надбавка**, **Премия**, **Удержания/Штрафы**, **Аванс**, **Больничные**, **Отпускные**, **Долг** – теперь соответствует структуре БД.

### База данных (db_update.php)
- Добавлена таблица **ktu** (ранее создавалась отдельным скриптом) – теперь создаётся автоматически при обновлении БД.
- Поле `work_ktu` в таблице `ktu` теперь имеет тип **REAL** (вместо INTEGER) – поддержка дробных значений КТУ.
- Миграция таблицы `employees` теперь корректно обрабатывает переименование `dop_premia` → `premia` и добавление поля `dolg`.

### Обработчик настроек (handler.php)
- Тип операции для КТУ изменён с `ktu` на **`setktu`** – теперь запросы из формы настроек обрабатываются корректно.
- Обновление КТУ теперь использует `work_id` как **TEXT** (ранее INTEGER) – поддержка строковых идентификаторов типов работ.
- Ставки в разделе «Часы» теперь принимают **дробные значения** (float) вместо целых чисел.

### API-методы (us_api.php)
- Добавлена структура для метода **`task_show`** – теперь можно получать детальную информацию о задании (пока не используется, но подготовлено для будущего функционала).
- Убрана устаревшая функция `getDivision()` – теперь логика выбора подразделений перенесена в `api.php`.

### Прочие исправления
- Исправлены синтаксические ошибки в шаблонах (кавычки, закрывающие теги).

## Детально по файлам

### `api.php`
- Вместо `getSettings()` теперь **`loadSettingsAndEmployees()`** – загружает справочники и сотрудников за один проход.
- Добавлена **`getDB()`** – единое подключение к SQLite с `PRAGMA journal_mode=WAL`.
- Поля сотрудников:
  - Добавлены: `Премия`, `Долг`.
  - Переименовано: `Доп.премия` → `Премия`.
  - В начале месяца (до `edit_delta`) обнуляются: аванс, отпускные, больничные, удержания.
- Расчётные поля:
  - `Итого ЗП` = ставка + ЗПЧасы + ЗПКТУ + стройработы + надбавки + премия – удержания.
  - `На руки` = Итого ЗП – аванс.
  - `Всего за мес.` = На руки + больничные + отпускные.
- Флаг `is_editable_archive` теперь вычисляется для архива и передаётся в шаблон.

### `archive.php` / `archive.tpl`
- Переименован флаг в `is_editable_archive`.

### `html.tpl`
- Теперь редактируемыми являются не только `Аванс`, но и `Премия`, `Больничные`, `Отпускные` (если `is_editable_archive`).
- В форме скрытое поле `type` теперь равно `archive` (вместо `avans`).
- Для каждого редактируемого поля определяется `db_field` (avans, premia, bolnichnye, otpusknye) и подставляется в `name`.
- Добавлена поддержка старого ключа `Доп.премия` (с пробелом и без) для отображения значения.
- Кнопка сохранения теперь «Внести изменения» и вызывает `requst_Json('settings','handler.php')`.

### `excel_export.php`
- Расширен список колонок до 21 (добавлены: Премия, Удержания/Штраф, Итого ЗП, Аванс, На руки, Больничные, Отпускные, Всего на карту за месяц, Долг).
- Формулы:
  - `Итого начислено Заработной платы` = `=H{line}+I{line}+J{line}+K{line}+L{line}+M{line}-N{line}` (где M – Премия, N – Удержания).
  - `Всего на карту за месяц` = `=Q{line}+R{line}+S{line}` (R – больничные, S – отпускные).
- Добавлена поддержка старого ключа `Доп.премия` при выводе значения в колонку `Премия`.

### `db_update.php`
- Миграция:
  - Добавлено поле `dolg` (REAL NOT NULL DEFAULT 0).
  - Переименовано `dop_premia` → `premia` (через создание новой таблицы и копирование).
- Обновлён список заголовков в `table_headers`:
  - Добавлены: `Итого ЗП`, `Всего за мес.`, `Долг`.
  - Изменён порядок и названия.

### `handler.php`
- Добавлен новый case `archive`:
  - Обновляет одновременно `premia`, `bolnichnye`, `otpusknye`, `avans`.
  - После обновления пересчитывает в JSON-архиве:
    - `Итого ЗП` (сумма всех начислений минус удержания)
    - `На руки` (Итого ЗП – аванс)
    - `Всего за мес.` (На руки + больничные + отпускные)
- В case `staff` добавлено поле `dolg`.
- Удалён отдельный case `avans` (объединён в `archive`).

### `payslip_template.tpl`
- Добавлены строки для `Премия` и `Удержания/Штраф`.
- Отдельно выводятся `Отпускные` и `Больничные` (если значение > 0).
- Теперь в письме два блока:
  1. Основная таблица с `Итого ЗП` и `На руки`.
  2. Дополнительная таблица с отпускными и больничными.

## [2.0.0] – 2026-08-22

### Добавлено
- **Архивация расчётов** – каждый успешный расчёт сохраняется в JSON-файл в папку `archive/` с именем `YYYY-MM-DD_город.json`.
- **Страница «Архив расчётов»** (`archive.php`) – позволяет просматривать ранее сохранённые расчёты, редактировать авансы и скачивать Excel-файл из архива.
- **Табель учёта рабочего времени** – отдельная кнопка на главной странице для отображения отработанных часов (обычные, сверхурочные, выходные) по каждому сотруднику.
- **Пакетная загрузка задач из API** – вместо двух запросов на каждого сотрудника теперь используются групповые запросы через `division_id_with_staff` и батчинг (по 100 ID за раз). Время расчёта значительно сокращено.
- **Гибкое управление авансами** – введена константа `edit_delta` (число дней от начала месяца). До этой даты аванс при новом расчёте обнуляется, после – берётся из базы. На странице расчёта поле «Аванс» становится редактируемым только в разрешённый период.
- **Email-рассылка расчётных листов** с использованием Smarty-шаблона (`payslip_template.tpl`) и условным выводом полей. Поддерживается загрузка архива по дате/городу и тестовый режим отправки на один email.
- **Улучшенный экспорт в Excel** – двухуровневая шапка с группировкой колонок «Часы», расчёт итогов и суммы «На руки» формулами Excel, фиксированные ширины для некоторых колонок, перенос текста в шапке, строка с периодом и датой формирования файла.
- **Скрипт инициализации `init.sh`** – интерактивно создаёт `conf.php`, запрашивая URL и API-ключ, автоматически устанавливает владельца `www-data`.
- **Модуль `payroll_archive.php`** – утилиты для работы с архивными файлами (чтение, поиск, нормализация, извлечение метаданных).
- **Новые шаблоны**: `archive.tpl`, `timesheet.tpl`, `payslip_template.tpl`, а также `api/html.tpl` и `api/timesheet.tpl` (вынесены в подпапку `templates/api/`).

### Изменено
- **Структура базы данных** (таблица `employees`):
  - Добавлены поля: `email` (TEXT), `oklad` (REAL), `otpusknye` (REAL), `bolnichnye` (REAL).
  - Удалено поле `shtraf` – штрафы теперь объединены с удержаниями.
  - Типы денежных полей изменены с INTEGER на REAL для поддержки дробных значений.
- **Новая таблица `table_headers`** – определяет порядок и названия колонок в отображении и Excel.
- **Миграция БД** в `db_update.php` теперь автоматически обновляет структуру при включённом режиме `update_mode`.
- **Использование UPSERT** (`INSERT ... ON CONFLICT`) вместо SELECT + UPDATE/INSERT – ускорение обновления справочников.
- **Переход на JSON-ответы** в `handler.php` – теперь все ответы приходят в формате `application/json`, добавлен тип операции `avans` для безопасного обновления только аванса с синхронизацией JSON-архива.
- **Рефакторинг `api.php`** – функции `excel()` и `html()` вынесены в отдельные файлы; добавлены новые case в `switch` (`timesheet`, `zarplata_from_archive`, `generate_excel`); улучшена обработка дат (время теперь 00:00:00 – 23:59:00).
- **Обновлён `ajax.js`** – добавлены обработчики для новых функций, переименована кнопка `#btn` → `#btnZarplata`, добавлена возможность указать целевой блок для `test()`, после сохранения авансов автоматически перезагружается архив.
- **Шаблоны**:
  - `header.tpl` – добавлена ссылка на «Архив расчётов».
  - `index.tpl` – добавлена кнопка «Табель», кнопка «Рассчитать» теперь имеет ID `btnZarplata`.
  - `html.tpl` – скрыты поля для передачи даты и города, колонка «Аванс» стала редактируемой (инпут) в зависимости от `is_editable_archive`, добавлена кнопка «Сохранить авансы», скрыт столбец «Оклад».
  - `setPeople.tpl` – изменён набор полей: добавлены «Оклад», «Отпускные», «Больничные», объединены «Удержания/Штрафы».
  - `settings.tpl` – кнопка «Сохранить» теперь использует `requst_Json`, кнопка «Обновить DB» передаёт целевой блок `result_form`.

### Исправлено
- Исправлено название ключа «Часы Выходные» в `tg.php` (заглавная буква В) для соответствия новым данным.
- Устранены дублирования сотрудников при обновлении из API (защита от повторов внутри подразделения).
- Исправлена обработка пустых дат – теперь корректно устанавливаются границы месяца.
- Исправлена работа с `division_id` при выборке сотрудников из БД.
- Исправлена проблема с `curl` – теперь используется статический хэндл с переиспользованием.
- Исправлена логика расчёта КТУ для строителей – теперь КТУ считается по часам, а не по classifier.

### Удалено
- Удалён файл `old_payslip_template.html` (заменён на `payslip_template.tpl`).
- Удалено поле `shtraf` из таблицы `employees` и связанного кода.
- Удалены комментарии и неиспользуемые переменные в `us_api.php`.
- Удалены старые версии файлов (`.old`).
