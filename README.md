# README

## Система расчёта зарплаты M3X

Веб-приложение для расчёта заработной платы сотрудников на основе данных из API UserSide, с возможностью архивации, редактирования авансов, экспорта в Excel и отправки расчётных листов по email.

---

### 🚀 Основные возможности

- **Расчёт зарплаты** по заданному городу и периоду с учётом отработанных часов, КТУ, строительных работ, надбавок и удержаний.
- **Табель учёта рабочего времени** – просмотр часов по каждому сотруднику.
- **Архивация расчётов** – каждый расчёт сохраняется в JSON-файл, который можно в любой момент загрузить и отредактировать.
- **Редактирование авансов** – с возможностью изменения только поля «Аванс» (в разрешённый период), с синхронизацией базы данных и архивного JSON.
- **Настройка параметров** (оклады, ставки, КТУ, фонды, коэффициенты) через веб-интерфейс.
- **Экспорт в Excel** – ведомость и табель с автоматическими формулами.
- **Отправка расчётных листов на email** каждому сотруднику (с поддержкой HTML-шаблонов).
- **Интеграция с Telegram** – отправка сводок в мессенджер (опционально).

---

### 📋 Требования

- **PHP** 7.4 или выше (рекомендуется 8.x)
- **Расширения**: `curl`, `sqlite3`, `json`, `mbstring`
- **Composer** (для установки PhpSpreadsheet)
- **Smarty** (включён в репозиторий)
- Доступ к API UserSide (URL и API-ключ)

---

### 🔧 Установка и настройка

1. **Клонируйте репозиторий** в корневую папку веб-сервера.

2. **Запустите скрипт инициализации** (он создаст `conf.php` с вашими данными):
   ```bash
   chmod +x init.sh
   ./init.sh
   ```
   Введите URL и API-ключ UserSide при запросе.

3. **Установите зависимости через Composer** (требуется PhpSpreadsheet):
   ```bash
   composer install
   ```

4. **Настройте права доступа**:
   - Папки `templates/compile/`, `templates/cache/`, `archive/` должны быть доступны для записи веб-сервером.
   - Файл `ktu.db` будет создан автоматически при первом запуске.

5. **Запустите обновление базы данных** из интерфейса (вкладка «Настройки оплаты» → кнопка «Обновить DB»). Это загрузит список подразделений и сотрудников из API и создаст необходимые таблицы.

---

### ⚙️ Конфигурация (conf.php)

Основные настройки задаются в `conf.php`:

```php
define("edit_delta", 9);                // Дней от начала месяца, когда разрешено редактирование аванса
define("URL", "https://.../api.php?");  // URL API UserSide
define("api_key", "ваш_ключ");          // Ваш API-ключ
define("update_mode", false);           // Включает/выключает автоматическую миграцию БД
```

Списки городов и подразделений для настроек также определяются здесь.

### 🖥 Использование

#### Главная страница (index.php)
- Выберите город и период (даты «с» и «по»).
- Нажмите **«Табель»** – просмотр отработанных часов.
- Нажмите **«Рассчитать»** – выполняется полный расчёт зарплаты, сохраняется архив, выводится таблица, создаётся Excel-файл.
- Кнопка **«Загрузить»** скачивает Excel-файл для текущего расчёта.

#### Архив расчётов (archive.php)
- Выберите город – автоматически подгрузится список доступных дат.
- Выберите дату и нажмите **«Показать из архива»** – отобразится сохранённая ведомость.
- Если разрешено редактирование аванса (в пределах `edit_delta` от даты расчёта), поля **«Аванс»**, **«Премия»**, **«Больничные»** и **«Отпускные»** станут редактируемыми.
  После внесения изменений нажмите **«Внести изменения»** – обновится БД и JSON-архив.
- Кнопка **«EXCEL»** скачает Excel-файл, сгенерированный из архивных данных.

#### Настройки оплаты (settings.php)
- Выберите нужный раздел (подразделение, фонд КТУ, КТУ работ, коэффициенты часов).
- Нажмите **«Настроить»** – отобразится форма с текущими значениями.
- Внесите изменения и нажмите **«Сохранить»** – данные будут записаны в БД.

#### Отправка писем (mail.php)
Запускается вручную или по крону. Поддерживает:
- `?city=Алчевск` – город для архива.
- `?archive_date=2026-08-17` – конкретная дата архива.
- `?archive_file=2026-08-17_m3x.json` – точное имя файла.
- Тестовый режим (константа `TEST_MODE`) – отправка только на один email.

### 🛠 Разработка и доработка

- Код документирован, функции вынесены в отдельные файлы.
- Для модификации логики расчёта смотрите `api.php` и `excel_export.php`.
- Для изменения внешнего вида используйте Smarty-шаблоны (папка `templates/`).
- При добавлении новых полей в расчёт не забудьте обновить `table_headers` и `setPeople.tpl`.
